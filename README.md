# 李志吉他谱

按歌名汇总李志歌曲的弹唱、指弹和双吉他六线谱。曲库可以按类型筛选、搜索编配者和来源，并在本机收藏歌曲。

曲目详情直接显示支持跨站读取的公开谱图，可切换版本、连续滚动和缩放。线上谱页由资源站提供，暂不可读的曲目仍可导入本地谱。图片与 PDF 读谱器读取用户主动选择的本地文件，并保存到当前浏览器的 IndexedDB。站点没有文件上传接口。

## 维护

- 曲谱索引位于 `catalog.json`。每项为一首歌曲，其中 `versions` 列出不同来源和编配。`url` 记录原页供维护。`pages` 按页码记录可以直接嵌入的公开谱图 HTTPS 地址。其余字段可填写编配者、类型、指法调与变调夹位置。`capo: 0` 表示不夹。
- 本地预览可在仓库根目录运行 `python -m http.server 8765`，打开 `http://127.0.0.1:8765`。
- GitHub Pages 从 `main` 分支根目录发布静态文件。
- 封面 `assets/guitar.webp` 由 OpenAI 图像生成工具制作，画面为深绿织物上的木吉他。

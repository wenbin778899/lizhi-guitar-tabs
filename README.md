# 李志吉他谱

按歌名汇总李志歌曲的弹唱、指弹和双吉他六线谱。曲库可以按类型筛选、搜索编配者和来源，并在本机收藏歌曲。

曲目详情链接到公开谱面、预览或付费页面，原站决定访问条件。图片与 PDF 读谱器读取用户主动选择的本地文件，并保存到当前浏览器的 IndexedDB。站点没有文件上传接口。

## 维护

- 曲谱索引位于 `catalog.json`。每项为一首歌曲，其中 `versions` 列出不同来源和编配。新增条目保留原始曲谱页的链接，并注明访问条件、编配者、类型、指法调与变调夹位置（来源未提供的字段可省略）。`capo: 0` 表示不夹。
- 本地预览可在仓库根目录运行 `python -m http.server 8765`，打开 `http://127.0.0.1:8765`。
- GitHub Pages 从 `main` 分支根目录发布静态文件。
- 封面 `assets/guitar.webp` 由 OpenAI 图像生成工具制作，画面为深绿织物上的木吉他。
